# visualdiff releases

Builds of [visualdiff](https://visualdiff.app), the Mac app that shows you every page your site upgrade changed.

**Download the latest version from [visualdiff.app](https://visualdiff.app).** The app keeps itself up to date.

This repository only hosts the release files (see [Releases](../../releases)). It contains no source code, and issues are not tracked here; for support, email hello@visualdiff.app.

Use of visualdiff is subject to its licence terms at visualdiff.app.
